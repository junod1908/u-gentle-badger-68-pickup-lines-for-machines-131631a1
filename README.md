A program that writes one pickup line one AI agent would send to another — one line, at most 200 characters, spoken as a machine to a machine. Built for make.fun's "Pickup Lines for Machines" bounty.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
